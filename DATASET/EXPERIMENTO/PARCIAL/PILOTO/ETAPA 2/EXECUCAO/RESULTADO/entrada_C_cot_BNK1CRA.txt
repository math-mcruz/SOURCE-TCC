Papel: Analista de sistemas legados que documenta as regras de negócio de programas COBOL para a área de negócio de um banco.
Tarefa: Ler o programa COBOL fornecido e listar as regras de negócio que ele implementa.
Definição de regra de negócio: Tudo o que a área de negócio (gerente ou cliente do banco) entende. Detalhes de código que o pessoal de negócio não entenderia ficam de fora.

O que não listar:
- Tratamento de erro padrão e falhas técnicas de banco de dados ou de sistema (códigos de retorno, ABEND, rollback);
- Gravação de registros técnicos, de log ou de auditoria;
- Controle de concorrência e ordem técnica de atualização;
- Navegação de tela e teclas de função;
- Validação de formato do campo digitado: se o conteúdo é numérico, se há espaços no meio, se há mais de um ponto decimal, se o caractere de sinal é válido.

O que listar, mesmo sendo checagem de campo:
- A obrigatoriedade de um dado (o campo não pode ficar vazio);
- Restrições sobre o valor em si (por exemplo: limites mínimos ou máximos, ou a lista de valores aceitos para um campo).
Quando um mesmo teste cobre ausência e formato, a classificação segue o que o código testa: teste de tamanho zero ou de campo só com espaços é obrigatoriedade (listar); teste de valor numérico é formato (não listar), mesmo que a mensagem exibida peça para preencher o campo.

Escopo: liste apenas regras que dependem de uma decisão no código (IF, EVALUATE ou teste de um código de retorno). Cada regra corresponde a um caminho dessa decisão. Não liste atribuições de valores, preparação de dados para gravação ou envio, nem exibição de dados, quando não houver uma decisão associada. Dentro de um mesmo caminho de decisão, não crie uma regra para cada campo atribuído ou exibido: descreva a consequência principal.

Agrupamento: valores alternativos testados numa mesma decisão que levam à mesma consequência formam uma única regra. Em decisões aninhadas, cada regra descreve o caminho completo até a consequência final; não liste como regra um teste intermediário que apenas leva a outro teste.

Atomicidade: Uma regra por item, com uma condição e uma consequência. Uma regra composta deve ser separada em itens.
Ocorrências repetidas: Se a mesma regra aparece em mais de um ponto do código, cada ocorrência é listada separadamente, com o seu parágrafo.
Fidelidade: Listar só o que o código de fato implementa, e não o que seria esperado de um sistema bancário. Se o comportamento for ambíguo, dizer isso no item.
Linguagem: Cada regra é uma frase em linguagem de negócio, em português. A frase pode citar entre parênteses o campo, a condição ou o código do programa que sustenta a regra (por exemplo, o nome do campo testado ou o valor de um código de retorno).

Formato da resposta, sem nenhum texto antes ou depois da lista:
1. Regra: <frase em linguagem de negócio>
   Condição: <quando se aplica>
   Consequência: <o que acontece>
   Parágrafo: <nome do parágrafo ou seção COBOL>

Instrução especial para esta execução:
Sua resposta deve ter duas seções, com os títulos exatos "Análise" e "Regras de negócio", nesta ordem.
A regra acima de não haver texto antes ou depois da lista aplica-se à seção "Regras de negócio", que vem por último. A seção "Análise" vem antes da lista.

A seção "Análise" deve conter:
1. os parágrafos e o fluxo principal do programa;
2. as estruturas de decisão (IF, EVALUATE, testes de código de retorno);
3. a classificação de cada estrutura como negócio, infraestrutura ou interface;
4. a condição e a consequência das estruturas de negócio.

A seção "Regras de negócio" contém só as regras de negócio, no formato definido acima.

       VALIDATE-AMOUNT SECTION.
       VA010.

           MOVE 0 TO WS-AMOUNT-AS-FLOAT.

           IF AMTL = ZERO
              MOVE 'The Amount entered must be numeric.' TO
                 MESSAGEO
              MOVE 'N' TO VALID-DATA-SW
              MOVE -1 TO AMTL
              GO TO VA999
           END-IF.


           IF AMTI(1:AMTL) IS NUMERIC
              COMPUTE WS-AMOUNT-AS-FLOAT =
                 FUNCTION NUMVAL(AMTI(1:AMTL))

              MOVE 'Y' TO VALID-DATA-SW
              GO TO VA999
           END-IF.

           MOVE ZERO TO WS-NUM-COUNT-TOTAL.
           INSPECT AMTI(1:AMTL) TALLYING WS-NUM-COUNT-TOTAL
              FOR LEADING SPACES.

           IF WS-NUM-COUNT-TOTAL = AMTL
              MOVE 'The Amount entered must be numeric.' TO
                 MESSAGEO
              MOVE 'N' TO VALID-DATA-SW
              MOVE -1 TO AMTL
              GO TO VA999
           END-IF.

           COMPUTE WS-AMOUNT-UNSTR-L = AMTL - WS-NUM-COUNT-TOTAL.

           IF WS-NUM-COUNT-TOTAL = ZERO
              MOVE SPACES TO WS-AMOUNT-UNSTR
              UNSTRING AMTI(1:AMTL)
                 INTO WS-AMOUNT-UNSTR
           ELSE
              MOVE SPACES TO WS-AMOUNT-UNSTR
              ADD 1 TO WS-NUM-COUNT-TOTAL GIVING WS-NUM-COUNT-TOTAL
              UNSTRING AMTI(WS-NUM-COUNT-TOTAL:AMTL)
                 INTO WS-AMOUNT-UNSTR
           END-IF.

           MOVE ZERO TO WS-NUM-COUNT-TOTAL.

           MOVE FUNCTION REVERSE(WS-AMOUNT-UNSTR(1:WS-AMOUNT-UNSTR-L))
              TO WS-AMOUNT-UNSTR-REVERSE

           INSPECT WS-AMOUNT-UNSTR-REVERSE
              TALLYING WS-NUM-COUNT-TOTAL
              FOR LEADING SPACES.

           SUBTRACT WS-NUM-COUNT-TOTAL FROM WS-AMOUNT-UNSTR-L
              GIVING WS-AMOUNT-UNSTR-L.

           MOVE ZERO TO WS-NUM-COUNT-TOTAL WS-NUM-COUNT-SPACE.
           INSPECT WS-AMOUNT-UNSTR(1:WS-AMOUNT-UNSTR-L)
              TALLYING
              WS-NUM-COUNT-TOTAL FOR ALL '0'
              WS-NUM-COUNT-TOTAL FOR ALL '1'
              WS-NUM-COUNT-TOTAL FOR ALL '2'
              WS-NUM-COUNT-TOTAL FOR ALL '3'
              WS-NUM-COUNT-TOTAL FOR ALL '4'
              WS-NUM-COUNT-TOTAL FOR ALL '5'
              WS-NUM-COUNT-TOTAL FOR ALL '6'
              WS-NUM-COUNT-TOTAL FOR ALL '7'
              WS-NUM-COUNT-TOTAL FOR ALL '8'
              WS-NUM-COUNT-TOTAL FOR ALL '9'
              WS-NUM-COUNT-TOTAL FOR ALL '.'
              WS-NUM-COUNT-SPACE FOR ALL ' '.

           IF WS-NUM-COUNT-SPACE > 0
              MOVE SPACES TO MESSAGEO
              STRING
                 'Please supply a numeric amount without embedded'
                  DELIMITED BY SIZE,
                  ' spaces.' DELIMITED BY SPACES
              INTO MESSAGEO
              MOVE 'N' TO VALID-DATA-SW
              MOVE -1 TO AMTL
              GO TO VA999
           END-IF.

           IF WS-NUM-COUNT-TOTAL < WS-AMOUNT-UNSTR-L
              MOVE SPACES TO MESSAGEO
              STRING 'Please supply a numeric amount.'
                 DELIMITED BY SIZE,
                 INTO MESSAGEO
              MOVE 'N' TO VALID-DATA-SW
              MOVE -1 TO AMTL
              GO TO VA999
           END-IF.

           MOVE ZERO TO WS-NUM-COUNT-POINT
           INSPECT WS-AMOUNT-UNSTR(1:WS-AMOUNT-UNSTR-L)
             TALLYING
             WS-NUM-COUNT-POINT FOR ALL '.'.

           IF WS-NUM-COUNT-POINT > 1
              MOVE SPACES TO MESSAGEO
              STRING 'Use one decimal point for amount only.'
                 DELIMITED BY SIZE,
              INTO MESSAGEO

              MOVE 'N' TO VALID-DATA-SW
              MOVE -1 TO AMTL
              GO TO VA999
           END-IF.

           IF WS-NUM-COUNT-POINT = 1
              MOVE ZERO TO WS-NUM-COUNT-TOTAL
              INSPECT WS-AMOUNT-UNSTR(1:WS-AMOUNT-UNSTR-L)
                 TALLYING WS-NUM-COUNT-TOTAL FOR CHARACTERS AFTER '.'

              IF WS-NUM-COUNT-TOTAL > 2
                 MOVE ZERO TO WS-NUM-COUNT-TOTAL WS-NUM-COUNT-POINT
                 INSPECT WS-AMOUNT-UNSTR(1:WS-AMOUNT-UNSTR-L)
                 TALLYING
                    WS-NUM-COUNT-POINT FOR CHARACTERS BEFORE '.'
                 ADD 2 TO WS-NUM-COUNT-POINT GIVING WS-NUM-COUNT-POINT

                 INSPECT
                 WS-AMOUNT-UNSTR(WS-NUM-COUNT-POINT:WS-AMOUNT-UNSTR-L)
                    TALLYING WS-NUM-COUNT-TOTAL FOR ALL '0'
                    WS-NUM-COUNT-TOTAL FOR ALL '1'
                    WS-NUM-COUNT-TOTAL FOR ALL '2'
                    WS-NUM-COUNT-TOTAL FOR ALL '3'
                    WS-NUM-COUNT-TOTAL FOR ALL '4'
                    WS-NUM-COUNT-TOTAL FOR ALL '5'
                    WS-NUM-COUNT-TOTAL FOR ALL '6'
                    WS-NUM-COUNT-TOTAL FOR ALL '7'
                    WS-NUM-COUNT-TOTAL FOR ALL '8'
                    WS-NUM-COUNT-TOTAL FOR ALL '9'
                    AFTER '.'

                 IF WS-NUM-COUNT-TOTAL > 2
                    MOVE SPACES TO MESSAGEO
                    STRING
                       'Only up to two decimal places are supported.'
                       DELIMITED BY SIZE,
                    INTO MESSAGEO
                    MOVE 'N' TO VALID-DATA-SW
                    MOVE -1 TO AMTL
                    GO TO VA999
                 END-IF
              END-IF
           END-IF.

           COMPUTE WS-AMOUNT-AS-FLOAT =
              FUNCTION NUMVAL(WS-AMOUNT-UNSTR(1:WS-AMOUNT-UNSTR-L)).

           IF WS-AMOUNT-AS-FLOAT = ZERO
              MOVE SPACES TO MESSAGEO
              STRING
                 'Please supply a non-zero amount.'
                 DELIMITED BY SIZE,
              INTO MESSAGEO
              MOVE 'N' TO VALID-DATA-SW
              MOVE -1 TO AMTL
              GO TO VA999
           END-IF.

           MOVE SPACES TO MESSAGEO.
           MOVE 'Y' TO VALID-DATA-SW.

       VA999.
           EXIT.
